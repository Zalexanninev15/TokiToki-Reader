# TokiToki Reader

![platform](https://img.shields.io/badge/platform-Android_8.0%2B-3DDC84.svg?logo=android)
![version](https://img.shields.io/badge/version-0.1_pre--alpha-orange)
![license](https://img.shields.io/badge/license-MIT-blue)

Читалка лент Mastodon и Misskey в одном приложении. Общая лента, отдельная вкладка на каждый аккаунт, синхронизация прочитанного с сервером там, где это вообще возможно.

> [!WARNING]
> Версия 0.1 pre-alpha. Многого ещё нет, что-то работает криво. Telegram пока не поддерживается.

## Возможности

**Лента**
- Общая лента из всех аккаунтов, отсортированная по времени
- Отдельная вкладка на каждый подключённый аккаунт, переключение свайпом
- В общей ленте у каждого поста подписано, откуда он пришёл: `@user@host (misskey · @вы@ваш.инстанс)`
- Подгрузка по 10 постов при прокрутке
- Локальный кэш, лента открывается без сети
- CW/спойлеры, бусты, цитаты, ответы

**Синхронизация прочитанного**
- Пост засчитывается прочитанным, когда реально показан на экране, а не когда загружен
- Mastodon: позиция уезжает на сервер через `markers`
- Misskey: только локально, у сервера нет такого API

**Изображения**
- В ленте с сохранением пропорций, полноэкранный просмотр с зумом
- Свайп вниз закрывает просмотр
- Сохранение в «Загрузки»

**Аккаунты**
- Несколько аккаунтов Mastodon и Misskey одновременно
- Список подписок с аватарками, экспорт в JSON в «Загрузки»
- Любой аккаунт можно временно выключить

**Оформление**
- Material You с динамическими цветами (Android 12+)
- Темы: системная, светлая, тёмная, AMOLED (`#000000`)
- Четыре размера шрифта
- Русский и английский

## Установка

Готовый APK — в [релизах](https://github.com/Zalexanninev15/TokiToki-Reader/releases). Собирается автоматически при каждом пуше в `main`.

Собрать самому (нужен JDK 17):

```bash
gradle wrapper --gradle-version 8.10.2
./gradlew :app:assembleDebug
```

## Подключение аккаунтов

**Mastodon** — вводите адрес инстанса, подтверждаете вход в браузере. Регистрировать приложение заранее не нужно.

**Misskey** — то же самое через MiAuth. Sharkey, Iceshrimp, CherryPick тоже подходят, приложение само определяет версию и форк.

## Ограничения

| Сервис | Прочитанное |
|---|---|
| Mastodon | Позиция в ленте, общая со всеми вашими клиентами |
| Misskey | Только локально |

> [!NOTE]
> У Mastodon это одна позиция на всю ленту, а не флаг на каждом посте — так устроен их API. Позиция никогда не двигается назад, чтобы не сбить прогресс, выставленный другим клиентом.

> [!IMPORTANT]
> У Misskey нет API для отметки прочитанного в ленте. Отмечаются только уведомления и упоминания. Ещё Misskey отдаёт ленту примерно за 30 дней, глубже история недоступна.

Pleroma, Akkoma и GoToSocial могут не поддерживать `markers` — тогда приложение переключится на локальный режим.

## Чего нет

Telegram, публикация и ответы, реакции и бусты, поиск по ленте, просмотр профиля внутри приложения, уведомления, скачивание постов для офлайна.
